# SewageTrace 污水治理

拍下污水照片 → AI 判定污染等级 → 自动生成工单上报监管部门 → 在地图上找机构、预约线下送检 → 跟踪治理进度。

一个完整的 Android 演示应用，包含客户端、云端识别反代网关和全流程截图。

> **这是演示项目，不是法定检测工具。** 识别结果是「画面视觉异常程度」的视觉线索评分，
> 与任何国家标准限值无关，不得作为执法或维权依据。机构名称与工单数据均为虚构。

## 快速开始

### 直接安装 APK

到 [Releases](../../releases) 下载最新 `SewageTrace-demo.apk`，直接装到 Android 8.0 以上设备。

装好后在登录页点「Continue with demo account」即可进入，不需要注册。

### 从源码构建

```bash
git clone <本仓库地址>
cd SewageTrace
./gradlew :app:assembleDebug      # macOS / Linux
gradlew.bat :app:assembleDebug    # Windows
```

产物：`app/build/outputs/apk/debug/app-debug.apk`（约 24 MB）

**环境要求**：Android Studio Narwhal+、JDK 17/21、**Android SDK Platform 37**、Build-Tools 36.0.0。

第一次用 Android Studio 打开时会自动生成 `local.properties`（指向你本机 SDK），
所以本仓库**不包含**这个文件 —— 这是正确的，不要手动提交它。

## 功能

四个 Tab：

| Tab | 功能 |
|---|---|
| **识别污水** | 拍照（真实相机）/ 从相册选择 → 污染指数(0–100) + 等级 R0–R4 + 置信度 + 疑似类型 + 证据维度 → 确认上报 |
| **地图** | MapLibre 矢量地图（3D 倾斜 / 全览 / 定位）、机构筛选（校内/政府/送检/污水厂/监测站）、**按污染等级筛选**、**长按新增标记 / 编辑 / 移动 / 删除**、从记录详情跳转聚焦、按距离排序、**预约线下送检** |
| **社区** | 同城/全国排行榜（7/30/全部）、我的工单进度、全平台工单动态 |
| **我的** | 资料统计、上报记录、我的预约、设置（语言/引擎/密钥/精度/匿名） |

### 场景：UM 校园 + 外部机构（两层受理）

课程要求 App 解决 UM 社区的真实问题，所以主场景放在校园，外部机构保留作升级通道：

| 上报位置 | 首个受理方 | 什么时候找外部机构 |
|---|---|---|
| **校内**（UM 校园围栏内，`data/Campus.kt`） | 最近的校内部门：JPPHB / UM Sustainability Centre / 宿舍管理处 | ① 人工或 AI 判为 **R4** → 建单即抄送；② 校内 300 m、72 h 内 ≥3 位不同用户印证 → 提级并移交。校内部门仍为主办方 |
| **校外** | 最近的外部政府机构（原有逻辑） | — |

- 演示场景各带示意坐标：Tasik Varsiti、宿舍排水渠、Sungai Pantai 在校内；Klang River 工业段、Sungai Kerayong 在校外。
- 演示数据里已有两条 72 h 内的 Tasik Varsiti 上报：用「绿藻与泡沫」场景再报一次，就能看到「3 人印证 → 提级 → 移交外部机构」的完整流程。
- 地图首次打开框住校园（粉色虚线为校园范围），「全览」再展开到校外机构；筛选里新增「校内」。
- 校内部门名称参照 UM 实际设置，**电话和坐标都是占位值**，录视频前建议用真实点位校正。



### 地图标记（MAP-03，方案 B：标记 = 我的上报点位）

| 操作 | 怎么做 | 规则 |
|---|---|---|
| 新增 | 长按地图 → 填名称、人工等级、描述 | 生成一条无照片的**草稿**（`engine = manual`），不建工单、不计入日限/查重/多人印证 |
| 编辑 | 点自己的点位 → 编辑 | 名称、人工等级、描述都可改；拍照记录只改人工等级，路由仍按 `max(人工, AI)` |
| 移动 | 点自己的点位 → 移动 → 拖地图对准准星 → 确认 | 只限**未进工单**的记录：进了工单的位置是证据 |
| 删除 | 点自己的点位 → 删除 → 确认 | 同上 |

别人的草稿不显示；自己的点位描边更粗，草稿半透明。业务规则在 `data/MarkerService.kt`。

### 持久化（Room）

五张表：`users` / `reports` / `tickets` / `ticket_logs` / `bookings`，结构与设计取舍写在 `data/db/AppDatabase.kt` 顶部注释。
机构是静态配置，不落库。原来几十处直接改列表的代码不用动：`DemoRepo` 的列表换成了 `PersistentList`，
任何写操作 250 ms 内合并成一次后台事务写入，退到后台时立即写。

> 日志文案存的是**资源名**而不是 `R.string` 整数 id：整数 id 每次编译都可能变，存 id 会让旧日志在升级后显示成别的句子。

**录视频前**：个人页 → 「重置演示数据」。种子里的时间（比如 72 小时内的 Tasik Varsiti 上报）是按重置时刻生成的。

单元测试：`./gradlew :app:testDebugUnitTest`（19 项：数据库映射往返、资源名跨版本、标记权限规则、校内外分流）。

- **登录**：`Sign in with Google`（UM Google 账号）
- **注册**：必须填 `学号@siswa.um.edu.my`，其他域名一律拒绝

### 拍照

`Take a photo` 会运行时申请 `CAMERA` 权限并调起系统相机（`ACTION_IMAGE_CAPTURE` +
`FileProvider`）；拒绝授权时显示引导卡，可跳到应用设置重新开启。也可从相册选图，
图片会被复制进应用私有目录后再识别。抓拍文件小于 1 KB 视为失败，不会送去识别。

### 污染等级

| 等级 | 指数区间 | 是否自动上报 |
|---|---|---|
| R4 重度 | ≥ 70 | ✅ 附加高危流程 |
| R3 中度 | 50–69 | ✅ |
| R2 轻度 | 30–49 | ✅ |
| R1 轻微 | 15–29 | ❌ 仅存草稿 |
| R0 无明显污染 | < 15 | ❌ 仅存草稿 |

### 关键业务规则

- **置信度为「低」时阻断上报**，只存本地记录并提示补拍（防误报）
- **R0/R1 不自动上报**，只存草稿（防滥用）
- 同一用户 24 小时内、200 米内同一水体重复上报 → 拒绝
- 同一用户每日上限 5 次
- 工单 8 阶段，**进度百分比由服务端按阶段权重计算，客户端只读**
- 72 小时内 1 公里内 ≥3 位不同用户报同一水体 → 自动提级
- 进度 <25% 且闲置 >7 天 → 自动催办

## 识别引擎

三档模式，设置里切换：

| 模式 | 行为 |
|---|---|
| **自动**（默认） | 有凭据且联网 → 云端；否则回退本机，**并在结果页显示回退原因** |
| 仅本机 | 只跑规则引擎，抓包零请求 |
| 仅云端 | 只调云端，失败报错不回退 |

### 本机引擎（离线）

`OnDeviceClassifier.kt` 是**规则模型，不是训练模型**：

```
index = 25×颜色与浊度 + 20×漂浮物 + 15×泡沫油膜 + 20×水体与岸边状态 + 10×富营养化 + 10×画质
```

### 云端引擎

调用 DeepSeek `deepseek-flash` 的 OpenAI 兼容视觉接口。四个硬约束写在
[`SewageTrace/README.md`](SewageTrace/README.md) 第四节，改代码前务必读。

## 密钥安全：为什么需要网关

**不要把 `sk-` 密钥硬编码进 APK。** 反编译 APK 或 root 手机导出配置都能拿到。

本项目用的是反向代理模式：

```
App ──X-ST-Token: st:xxxx──▶ 你的网关 ──Authorization: Bearer sk-真key──▶ api.deepseek.com
```

APK 只持有网关签发的 `st:` 令牌，真密钥留在服务器。攻击者拿到令牌只能刷这个令牌的配额，
拿不到密钥，也换不了模型。

网关自带：模型白名单、字段白名单、每分钟+每天双限流、令牌吊销、令牌只存哈希。

```bash
cd gateway
cp .env.example .env      # 填 DEEPSEEK_API_KEY 和 ISSUE_SECRET
node server.js            # 零 npm 依赖
node test/forward.test.js # 12 项自测，不消耗真实额度
```

**本仓库不含任何真实密钥**，已做全树扫描确认。

## 演示版与正式版的差距

| 项目 | 本仓库 | 正式版需要 |
|---|---|---|
| 地图 | MapLibre + OpenFreeMap 真实矢量地图（2D/3D 切换、底部面板），离线时只剩列表 | 离线瓦片包；机构点位换成真实名录 |
| 机构数据 | 校内部门参照 UM 实际设置（电话/坐标为占位），外部机构为虚构名称 | 校方与政府公布的名录 |
| 后端 | 无，全本地 | 真实 API + 鉴权 |
| 上报 | 只写本地工单 | 对接政务系统 / 12345 |
| 政府处理 | 「模拟推进一阶段」按钮 | 真实状态流转 |
| 照片 | Canvas 合成 / 系统相机实拍 | CameraX + EXIF |
| 账号 | 演示用 Google 账号选择框 + 校邮箱格式校验 | 真实 Google OAuth + 学校 SSO 验证 |
| 识别校准 | 未做 | 用实测报告建校准数据集 |
| 持久化 | Room（SQLite）本地数据库，杀进程后保留；个人页可「重置演示数据」 | 云端同步 |
